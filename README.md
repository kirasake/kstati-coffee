# Кстати: кофейня на набережной

Концепт-сайт для портфолио: лендинг кофейни «Кстати» на набережной Дона в Ростове-на-Дону.

Это **не официальный сайт кофейни**. Меню, цены, адрес и часы работы взяты с Яндекс.Карт (24.11.2026), все фотографии сгенерированы нейросетью.

## Что внутри

- Прелоадер, парящие напитки с параллаксом за курсором и пар над чашкой на первом экране
- Меню во вкладках (19 позиций) с каскадной анимацией
- Закреплённая секция «День на набережной» с горизонтальной прокруткой и сменой цвета от утра к ночи
- Инерционная прокрутка, появление блоков при скролле, магнитные кнопки
- Адаптив, поддержка `prefers-reduced-motion`, всё читается без JS

Стек: HTML, CSS, JS, [GSAP](https://gsap.com/) + ScrollTrigger, [Lenis](https://lenis.darkroom.engineering/). Без сборки.

## Запуск

```
py -3 -m http.server 5173
```

Открыть http://localhost:5173. Проверка данных: `node tools/check.mjs`.
