## Что должно заработать

У сайта есть полный набор собственных фотографий в одном стиле: пять вырезов с прозрачным фоном для первого экрана, фото для каждой из 19 позиций меню и атмосферные кадры набережной — всё сгенерировано в Higgsfield, без текста и вывесок на картинках.

## Из брифа, дословно

> «если можешь используй фотки и все цены которые на яндексе расположены и их картинки если нет можешь генерировать в нейронке которую я тебе добавлял»

## Разделы спецификации

`spec.md` → «Решение» (общее: единый стиль фото), «Решения по реализации» (фото); `interfaces.md` → «Имена изображений».

## Критерии приёмки

- [ ] В `assets/img/` есть все файлы из списка «Имена изображений» в `interfaces.md`, с ровно такими именами
- [ ] `hero-*.png` — с настоящим прозрачным фоном (альфа-канал), объект целиком в кадре
- [ ] Фото меню — 4:5, один фон и свет у всех 19; напиток узнаваемо соответствует названию (матча — зелёная, лимонад киви–лайм — зелёный с лаймом, бамбл — слоистый апельсиновый сок с эспрессо и т.д.)
- [ ] Каждый JPG ≤ ~350 КБ, длинная сторона ≤ 1400 px; PNG ≤ ~900 КБ
- [ ] `assets/img/CREDITS.md`: файл → модель → промпт
