# Спецификация: сайт кофейни «Кстати» (концепт для портфолио)

## Задача
Начинающему веб-дизайнеру нужен в портфолио сильный кейс: сайт для реальной кофейни, у которой своего сайта нет. Выбрана «Кстати» — кофейня на набережной Дона в Ростове-на-Дону. Сайт должен выглядеть как в двух присланных референсах (тёплый бежево-кофейный стиль, серифные заголовки, много фото напитков) и впечатлять плавными и интересными анимациями.

## Решение
Одностраничный сайт (лендинг), который открывается с локального сервера и двойным кликом по `index.html`, без сборки.

Секции сверху вниз:
1. **Прелоадер** — стакан наполняется кофе, затем сцена «раскрывается» в первый экран. Не дольше ~1,8 с; при повторной загрузке в той же вкладке (sessionStorage) пропускается.
2. **Шапка** — логотип «Кстати» (сериф), навигация: Меню · О нас · День на набережной · Отзывы · Контакты, кнопка «Позвонить» (`tel:+79953779121`). Липкая; при прокрутке вниз прячется, вверх — появляется; фон с размытием. На телефоне — бургер с полноэкранным меню, которое открывается анимацией. Над шапкой тонкий топбар как в референсе 1: «Кофе на набережной Дона» слева, «Ежедневно 09:00–00:00» справа (на телефоне скрыт).
3. **Первый экран** — заголовок «Кофе с видом на Дон», подводка рукописным шрифтом «кстати, о кофе…», короткий текст про набережную, кнопки «Смотреть меню» и «Как добраться». Вокруг — вырезанные (прозрачный фон) напитки и зёрна: капучино сверху, айс-латте, лимонад киви–лайм, зёрна, лайм с мятой. Они появляются по очереди, плавно «парят», сдвигаются за курсором (параллакс по глубине) и разлетаются/уходят при прокрутке. Над капучино — анимированный пар (SVG). Бейдж «4,9 ★ · 128 оценок на Яндекс.Картах», число досчитывает от 0.
4. **Бегущая строка** — названия напитков через «·», бесконечно; скорость и направление зависят от скорости прокрутки.
5. **Почему «Кстати»** (О нас) — три карточки с фото как в референсе 1: «Прямо на набережной» (вид на Дон, зонтики летней площадки), «Большие объёмы — честные цены» (айс-напитки 450 мл, капучино от 215 ₽), «Можно с собакой и с собой» (кофе с собой, оплата картой, со всеми животными). Фото раскрываются маской при появлении, текст — построчно.
5б. **Хиты** (как «Our Menu Highlights» референса 1) — четыре карточки с фото и ценой: Капучино 215 ₽, Айс латте 299 ₽, Лимонад киви–лайм 335 ₽, Раф 275 ₽, кнопка «Всё меню» к секции меню. Карточки въезжают каскадом, фото слегка «дышит» на наведении.
6. **Меню** — вкладки «Классика» (10) · «Айс кофе» (5) · «Лимонады» (4), **все 19 позиций** с фото, названием, объёмом и ценой ровно как в `menu-yandex.md`. Смена вкладки — каскадная анимация карточек (старые уходят, новые приходят со сдвигом). Карточка на наведении: лёгкий 3D-наклон за курсором и приближение фото. Под меню мелко: «Цены с Яндекс.Карт на 24.11.2026, могут отличаться». Промо-строку «Попробуй лето на вкус — 1 ₽» на сайт не выводим.
7. **День на набережной** — закреплённая секция с горизонтальной прокруткой: 4 панели «09:00 — утро, эспрессо», «13:00 — полдень, айс-латте», «18:00 — вечер, лимонад», «23:30 — ночь, какао», у каждой фото, короткий текст и цена напитка из меню. Фон секции плавно меняет цвет от утреннего светлого к ночному тёмному по ходу прокрутки, часы в углу показывают время, «перещёлкивая» по прогрессу. На телефоне (<768 px) — вертикальный список панелей, смена цвета по мере прокрутки сохраняется.
8. **Отзывы** — крупное «4,9» и «128 оценок», три цитаты с Яндекса (имя и дата как там, текст из `menu-yandex.md`) — карусель, листаемая стрелками и перетаскиванием, с плавным переходом.
9. **Контакты** (как «Visit Us Today» референса 1) — адрес «Береговая ул., 12, Ростов-на-Дону», «Ежедневно 09:00–00:00», телефон ссылкой, особенности (кофе с собой, оплата картой, можно с животными), встроенная карта Яндекса (виджет организации, `https://yandex.ru/map-widget/v1/?oid=193387289977`, ленивая загрузка) и кнопка «Построить маршрут» на `https://yandex.ru/maps/org/kstati/193387289977/`. Три фото рядом с текстом (как в референсе 1: терраса, бариста с латте-артом, стакан у реки). Индикатор «Сейчас открыто · до 00:00» / «Сейчас закрыто · откроемся в 09:00» по времени Ростова (UTC+3), с пульсирующей точкой.
9б. **Баннер** (как нижний баннер референса 2) — широкое фото стаканов на парапете у реки с крупной надписью «Заходи, кстати» и кнопкой «Построить маршрут»; фото движется параллаксом медленнее страницы.
10. **Футер** — логотип, адрес, телефон, часы, якоря; строка «Концепт-сайт для портфолио. Не является официальным сайтом кофейни. Данные — Яндекс.Карты, 24.11.2026».

Общее поведение:
- Плавная инерционная прокрутка всей страницы; якорные ссылки прокручивают плавно с учётом шапки.
- Появление блоков при прокрутке: заголовки по словам/строкам, изображения маской, карточки каскадом.
- Магнитные кнопки (слегка тянутся к курсору) на устройствах с мышью.
- `prefers-reduced-motion: reduce` — анимации отключены или заменены мгновенным появлением, нет параллакса, пара, пина и инерции; весь контент виден.
- Без JS или при недоступном CDN — весь контент виден и читаем; меню показывает все три группы подряд.
- Адаптив: телефон 360–430 px без горизонтальной прокрутки страницы, планшет, десктоп до 1920 px.
- Все фото сгенерированы в Higgsfield, единый стиль: тёплый дневной свет, бежевый лён/светлое дерево, кофейная гамма; без текста и вывесок на фото.
- Доступность: alt у фото, видимый фокус, кнопки — `<button>`, вкладки с `role="tab"`/`aria-selected`, контраст текста ≥ 4.5:1.

## Решения по реализации
- Статика HTML + CSS + JS, без сборки — открывается где угодно, легко выложить на GitHub Pages.
- GSAP 3.12.5 + ScrollTrigger (cdnjs) — плавные scroll-анимации и пины; Lenis 1.1.13 (unpkg) — инерционная прокрутка. Почему: стандарт для «наградных» анимированных сайтов, без сборки.
- Шрифты Google Fonts с кириллицей: Playfair Display (заголовки), Manrope (текст), Marck Script (рукописная подводка).
- Палитра: крем `#F4ECE1`, бежевый `#E8D9C5`, кофе `#5B3A29`, эспрессо `#2B1B14`, карамель `#C8894B`, лайм `#9DBB4A` (лимонады).
- Фото: GPT Image 2.6 в Higgsfield; вырезы первого экрана — PNG с прозрачным фоном; остальное — JPG ≤ ~300 КБ.
- Меню рендерится в HTML сразу (контент без JS), `js/menu-data.js` — тот же список данными для JS.

## Вне рамок
| Требование | Почему не сейчас |
|---|---|
| R05 — фото с Яндекса | загружены посетителями/владельцем, права не наши, качество низкое → генерация (R08), как разрешил пользователь |
| Онлайн-заказ, корзина, бронь (кнопка «Order online» референса 1) | у кофейни нет онлайн-заказа — вместо неё честная кнопка «Позвонить» |
| Подписка на рассылку (референс 1) | у кофейни нет рассылки; форма, которая никуда не отправляет, была бы фальшивкой |
| Акционный блок (референс 2) | реальных акций на Яндексе нет; промо «1 ₽» — служебная запись |
| Публикация в интернет | действие наружу — только по слову пользователя |
